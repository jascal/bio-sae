# architecture Esm2T68m

> ESM-2 protein language model — encoder-only transformer. 6 pre-norm blocks with rotary positional embeddings (RoPE is applied inside attention; n-orca v1 represents attention as a plain MultiHeadAttention, so the positional mechanism is left implicit). Generated by `n-orca hf convert` from a Hugging Face config.
